agentport panel (Companion, 127.0.0.1 only)
==========================================

+--------------------------------------------------------------------------------+
| top bar: logo · server (Switch, Connect) · approval policy · bell · language   |
|          · theme · help · GitHub · stop Companion (two clicks)                 |
+--------------------------------------------------------------------------------+
| Requests from the agent (cards: single, or batch with checkboxes)              |
|   :5432 → localhost:5432   [reason]   [Approve] [Deny] [duration] [settings]    |
|   busy port box: use another free port / stop the program (if stoppable)       |
+--------------------------------------------------------------------------------+
| tabs: Open · Detected on server · Closed · Activity        [filter] [/ open]   |
|   Open: group by Group | Session | List · close all on the server             |
|         row: [x] :remote → localhost:local  name  chips  [open][pin][edit][▾][x] |
|   Closed: Reopen · Reopen with changes · Remove from history                    |
|   Activity: newest first                                                       |
+--------------------------------------------------------------------------------+
| status: Tunnel · Agent sessions · Ports open · Panel                           |
+--------------------------------------------------------------------------------+
Dialogs: port edit (local port check), close confirmation (notified sessions),
switch server (close N and switch / keep open and switch / remember), about (5 tabs),
keyboard shortcuts (A, R, 1-4, /, ?, Esc).
